# 自費サービス記録帳

訪問介護などの自費サービスで、スマホに次のことを記録する無料アプリです。

- 利用日と、何時何分〜何時何分の利用か（利用時間と料金を自動計算）
- 何をしたか（項目を選ぶ＋くわしく書く）
- ご本人の様子
- 利用者の手書きサイン（指で書けます）

## 使い方

1. スマホでアプリのURLを開く
2. 「ホーム画面に追加」を押す（iPhoneはSafariの共有ボタン → 「ホーム画面に追加」）
3. あとはホーム画面のアイコンから使う

## 記録の保存場所

記録とサインは **そのスマホのブラウザの中だけ** に保存されます。
サーバーはなく、ログインもアクセス解析もありません。作者を含め、だれにも送られません。

そのため、スマホをなくしたり機種変更したりすると記録は消えます。
「設定」→「バックアップを保存」で、ときどきGoogleドライブやiCloudなどに保存してください。
新しいスマホでは「バックアップから戻す」で戻せます。

## 注意

- 無料・無保証です。問い合わせ窓口やサポートはありません。
- 手書きサインは「利用者が内容を確認した」ことの記録で、本人確認や契約書の代わりにはなりません。
- 介護保険サービスの正式な記録として使う場合は、事業所ごとに保存方法の決まりを確認してください。

## 公開する人向け：GitHub Pages に置く手順

このフォルダのファイルを置くだけで動きます（ビルド不要）。

1. GitHub のアカウントを作る（個人名の入らないアプリ用の名前がおすすめ）
2. 新しいリポジトリを Public で作り、このフォルダのファイルを全部アップロード
3. リポジトリの Settings → Pages → Branch を `main` / `/(root)` にして Save
4. 数分後に `https://アカウント名.github.io/リポジトリ名/` で開けるようになる

**公開したアカウントは削除しないでください。** 削除後に同じ名前を他人が取ると、
そのURLで使っていた人のスマホに残る記録を読めるページを置けてしまいます。
更新しない場合も、アカウントだけは残しておいてください。

`index.html` を更新すると、使っている人のスマホが次にネットにつながったときに新しい版になります。
アイコンなどほかのファイルを差し替えたときは、`sw.js` の `VERSION` も上げてください。
